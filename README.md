# FinAI – Personal Finance Tracker

FinAI is an AI-powered personal finance management system designed to help users
track expenses, manage budgets, and predict future monthly expenses.

## Objectives
- To track daily and monthly expenses
- To analyze spending patterns
- To predict future expenses using machine learning
- To provide smart saving and investment suggestions

## Features
- Expense tracking and categorization
- Monthly budget monitoring with alerts
- AI-based expense prediction
- Smart saving goal advisor
- Investment suggestions based on surplus

## Technology Stack
- Frontend: React + TypeScript
- Backend: FastAPI (Python)
- Database: SQLite
- Machine Learning: TensorFlow, Scikit-learn,ANN

## Project Structure
- frontend/: User interface of the application
- backend/: API, database, and ML model
- README.md: Project documentation
- .gitignore: Ignored files configuration

## Conclusion
FinAI provides a simple and intelligent approach to personal finance management
by combining web technologies with machine learning.
